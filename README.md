# 🌌 CosmoTab – Custom New Tab Page

> A custom, space-themed browser new tab page built for the Stardance “Give Your Website a Pulse” mission.

![CosmoTab Banner](https://images.unsplash.com/photo-1506703719100-a0f3a48c0f86?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

- **Cosmic Aesthetic:** Immersive space-themed background and modern glassmorphism UI.
- **Interactive Todo List:** Track personal daily work, tasks, and productivity right from your new tab.
- **Quick Links Section:** Instant access to your favorite sites and everyday tools and stores locally .
- **Lightweight & Fast:** Optimized vanilla web code built for speed and minimal resource usage.
